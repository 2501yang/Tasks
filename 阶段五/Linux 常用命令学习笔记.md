# Linux 常用命令学习笔记

#### 一、目录与文件操作

1. 查看目录内容

-  ls ：列出当前目录下的文件/文件夹
-  ls -l ：详细列表（权限、大小、时间等）
-  ls -lh ：带单位显示文件大小（KB/MB）

2. 切换目录

-  cd 目录名 ：进入某个目录
-  cd / ：进入根目录
-  cd ~  或  cd ：回到家目录
-  cd .. ：回到上一级目录

3. 查看当前路径

-  pwd ：显示当前所在的绝对路径

4. 创建/删除文件/目录

-  touch 文件名 ：创建空文件

-  mkdir 目录名 ：创建目录

-  mkdir -p a/b/c ：创建多级目录（自动补全父目录）

-  rm 文件名 ：删除文件

-  rm -r 目录名 ：删除目录及里面所有内容

-  rm -f 文件名 ：强制删除，不提示确认

5. 复制/移动/重命名

-  cp 源文件 目标路径 ：复制文件

-  cp -r 源目录 目标路径 ：复制目录

-  mv 源文件 目标路径 ：移动文件/目录

-  mv 旧名 新名 ：重命名

#### 二、文件内容查看与编辑

1. 查看文件内容

-  cat 文件名 ：直接输出全部内容

-  less 文件名 ：分页查看（上下翻页， q  退出）

-  head 文件名 ：默认显示前10行

-  tail 文件名 ：默认显示后10行

-  tail -f 文件名 ：实时跟踪文件新增内容（看日志常用）

2. 简单编辑

-  nano 文件名 ：简单文本编辑器

- 编辑完： Ctrl+O  保存， Ctrl+X  退出

-  vim 文件名 ：功能更强的编辑器

#### 三、权限与用户管理

1. 权限查看与修改

- ls -l ：查看文件权限

- chmod 权限 文件名 ：修改权限

  例： chmod 755 test.sh 

2. 切换用户/提权

-  su 用户名 ：切换用户

-  sudo 命令 ：以管理员权限执行命令

-  sudo -i ：切换到 root 用户

#### 四、系统与进程管理

1. 系统信息

-  uname -a ：查看系统内核信息
-  df -h ：查看磁盘使用情况
-  du -sh 目录 ：查看目录占用大小
-  free -h ：查看内存使用情况
-  top ：实时查看系统进程与资源占用（ q  退出）

2. 进程管理

-  ps ：查看当前终端进程

-  ps aux ：查看所有进程

-   systemctl ：管理 systemd 服务

-  kill 进程ID ：结束进程

-  kill -9 进程ID ：强制结束进程

#### 五、网络相关

- ifconfig  或  ip addr ：查看网卡与IP地址

- ping 域名/IP ：测试网络连通

- curl 网址 ：获取网页内容/接口数据（模拟网络请求，常用于测试）

- netstat：查看网络连接和端口占用情况

  netstat -tulpn ：列出所有正在监听的 TCP/UDP 端口，并显示对应的进程 

  netstat -an ：查看所有网络连接（包括监听和已建立的）

  netstat-l ：只显示正在监听（Listening）的端口

-  wget 下载链接 ：下载文件

#### 六、查找与搜索

- find 路径 -name "文件名" ：查找文件

  例： find /home -name "*.log" 

- grep "关键词" 文件名 ：在文件中搜索关键词

  例： grep "error" log.txt
