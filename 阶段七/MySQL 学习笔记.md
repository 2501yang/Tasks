# MySQL 学习笔记

#### 一、MySQL 前世今生

诞生：1995 年由瑞典 MySQL AB 公司开发，核心特点是开源、轻量、高性能，专门用于管理关系型数据库（数据以表格形式存储，有明确的行 / 列结构）。
发展：
2008 年被 Sun 公司收购，2009 年 Sun 又被 Oracle 收购，MySQL 归 Oracle 所有；
因为开源属性，衍生出 MariaDB（MySQL 原团队开发，完全兼容 MySQL，新手可等同学习）；
现状：全球最流行的开源关系型数据库，Web 开发（比如电商、博客、后台系统）的标配，Go/Python/Java 等语言都能无缝对接。
核心优势：容易部署、支持跨平台（Linux/Windows）、适配中小规模业务场景

#### 二、MySQL 基础概念

1，数据库 (Database)：
就像一个文件夹，用来存放多张表。
例如：shop_db (商城数据库), blog_db (博客数据库)。

2，表 (Table)：
就像文件夹里的 Excel 文件。
例如：users (用户表), orders (订单表)。
3，字段/列 (Column/Field)：
表中的竖列，定义数据的类型。
例如：id, username, password

4，记录/行 (Row/Record)：
表中的横行，代表一条具体的数据。
例如：1, 'zhangsan', '123'。,

5，主键 (Primary Key)：
能唯一标识一条记录的字段，通常设为 id，不能重复，不能为空

6，外键 (Foreign Key)：
用于关联另一张表的字段，建立表与表之间的关系。

##### 数据表结构与关联方式

一，常见数据类型
创建表时，必须指定每个字段存什么类型的数据：

int: 整数 (如年龄、ID)。
varchar(n): 可变长度字符串 (如用户名，n 代表最大长度)。
text: 长文本 (如文章內容)。
date/datetime: 日期和时间。
decimal(m, d): 精确小数 (如金额，m 是总位数，d 是小数位)。

二，表之间的关联方式

(1) 一对一 (1:1)
场景：一个用户对应一个身份证信息。
实现：在任意一张表中加入另一张表的主键作为外键，并设为唯一。
示例：users 表中有 id_card_id。
(2) 一对多 (1:N) —— 最常见
场景：一个班级有多个学生，一个学生只属于一个班级。
实现：在“多”的那张表（学生表）中，加入“一”的那张表（班级表）的主键

示例：students 表中有 class_id。

(3)多对多 (N:M)
场景：一个学生选多门课，一门课被多个学生选。
实现：需要创建第三张中间表。
示例：student_course 表，包含 student_id 和 course_id。

##### SQL 基本操作 (CRUD) 

CRUD 是指 Create(增), Read(查), Update(改), Delete(删)

Create (增加数据)
语法：INSERT INTO 表名 (字段 1, 字段 2) VALUES (值 1, 值 2);

Read (查询数据) 
语法：SELECT 字段 FROM 表名 WHERE 条件 ORDER BY 排序 LIMIT 限制;

排序：升序ASC    降序DESC

限制数量 (LIMIT) - 常用于分页：

| SQL 语句     | 含义                   | 返回记录  |
| ------------ | ---------------------- | --------- |
| `LIMIT 0, 2` | 从第 0 条开始，取 2 条 | 第 1-2 条 |
| `LIMIT 2, 2` | 从第 2 条开始，取 2 条 | 第 3-4 条 |
| `LIMIT 4, 2` | 从第 4 条开始，取 2 条 | 第 5-6 条 |
| `LIMIT 2`    | 等价于 `LIMIT 0, 2`    | 第 1-2 条 |

Update (修改数据)
语法：UPDATE 表名 SET 字段=新值 WHERE 条件;

. Delete (删除数据)
语法：DELETE FROM 表名 WHERE 条件;

**其他注意：**

1. 在执行 `UPDATE` 和 `DELETE` 操作时，**务必加上 `WHERE` 条件**。如果不加，将操作表中的**所有数据**。
2. SQL 语句中，字符串值和日期值必须使用**单引号** `' '` 包裹。
3. 每条 SQL 语句末尾建议使用分号 `;` 结束。
4. SQL 关键字（如 `SELECT`, `FROM`）不区分大小写，但建议统一大写以提高可读性；表名和列名在 Linux 环境下通常区分大小写。
